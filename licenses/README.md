# Included license texts

This directory accompanies CalcioTotale source copies and executable packages. The files apply only to the corresponding third-party material; they do not replace the proprietary terms in the project-root `LICENSE`. The separate `data/` football content package is outside the scope of that proprietary license and is not covered by the component license texts collected here.

The Italian, English and Spanish CalcioTotale localisations are project material covered by the root license. The language-selector PNG files are not represented by `MIT-FLAG-ICONS.txt`; see `THIRD_PARTY_NOTICES.md` for the distinction between those project-provided assets and applicable upstream `flag-icons` SVG files.

- `PYTHON-3.12-LICENSE.txt` — Python 3.12 and software incorporated into that distribution.
- `LGPL-3.0.txt` and `GPL-3.0.txt` — general GNU terms relevant to the PySide6/Qt Community distribution used by automated builds.
- `PYINSTALLER-COPYING.txt` — PyInstaller, including its bootloader exception and runtime-hook terms.
- `MIT-CMU-PILLOW.txt` — Pillow, used during packaging.
- `APACHE-2.0.txt` — applicable Google interface icons.
- `OFL-RED-HAT-DISPLAY-1.1.txt` — Red Hat Display.
- `OFL-OXANIUM-1.1.txt` — Oxanium.
- `MIT-FLAG-ICONS.txt` — applicable `flag-icons` SVG material.
- `CC0-KENNEY-CURSOR-PACK.txt` — four static cursors from the Kenney Cursor Pack.

`THIRD_PARTY_NOTICES.md` is the maintained inventory and explains where each component is used. Every release must also be checked against the exact dependency versions listed in its `BUILD_COMPONENTS.txt`; Qt/PySide packages may require additional module-specific notices or compliance material beyond these general license texts.
