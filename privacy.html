Privacy Policy

CalcioTotale version 1.0.1 is a local, single-player football management application built with Python and PySide6 and accompanied by a separate, replaceable 2026-27 football content package. Its reference environment is desktop Linux. The interface is available in Italian and English. Italian is selected by default only when the system language is Italian; every other system language defaults to English. The application simulates football seasons, club and squad management, finances, transfers, marketing, facilities and matches.

The application does not collect, transmit, sell or share personal data. All gameplay and simulation logic run locally on the user's device. CalcioTotale does not require an account, telemetry, analytics, advertising services or a remote server, and the runtime does not intentionally make network requests during normal gameplay.

The user may enter a display name for the CEO profile. If the user chooses to enter a real name or other identifying text, that text is stored only inside the local career files. Save data may also include the selected club, career mode, chosen management-control level, squads, staff, fixtures, results, finances, transfers, facilities, news and the other information needed to restore game progress.

No profile name, save payload, selected club, match result or other progress data is sent by the application to Eleòra or to an external service.

The following local files are read or may be written during normal use:

  • Career payloads Up to nine slots are stored as gzip-compressed JSON in user/slotN.json.gz. Portable Windows and Linux builds keep this directory beside the executable; the Fedora RPM uses ${XDG_DATA_HOME:-$HOME/.local/share}/calciototale/user/; macOS uses ~/Library/Application Support/CalcioTotale/user/. The files remain on the user's device unless the user copies, backs up or shares them.
  • Slot summaries The game may create user/slotN.meta.json with a plain-JSON summary used by the load screen, containing only profile name, club, career mode, management-control level and in-game date.
  • Local preferences user/preferences.json may store the selected interface language and other local display preferences. A language selected from the game menu is applied on the next launch; clicking the same switch again before restarting cancels the pending change. The file contains no career payload or online identifier.
  • Separate football content package The replaceable package under data/ is separate from the application. Its gzip-compressed JSON data is read to initialize clubs, players, seasonal content and the colours and patterns used to generate identifying team shirts. The associated local images are used for competition visuals.
  • Local assets Images, fonts, icons and UI graphics are loaded from the local assets/ directory. They are not downloaded at runtime.
  • Temporary caches Replaceable PNG renderings of local icons may be generated under the operating system's temporary directory, currently in calciototale_news_icons and calciototale_icon_cache. They contain no career or profile data.
  • Display probe At startup, a short-lived calciototale-display-*.json file may be created in the operating system's temporary directory to pass the primary display geometry and scaling factor between local application processes. The game removes it after the probe and it contains no career or profile data.

The game does not create an online profile, persistent telemetry identifier, cookie or cloud backup. Root or administrator privileges are not required. The application runs as the current user and needs write access only where its local saves and operating-system temporary files are stored.

The user controls these local files and can remove career data by deleting the corresponding slotN.json.gz and slotN.meta.json files. Deleting preferences.json resets stored interface preferences, including language selection, so the next launch returns to the system-language rule described above. Temporary icon caches can also be deleted and are regenerated when required. Copies created through backups, synchronisation software or manual sharing are controlled by the user and by the chosen third-party service, not by CalcioTotale.

The About dialog contains links to official Eleòra pages. They are opened in the user's default browser only when selected. The game does not send career or profile data with those links; any subsequent connection is made by the browser and is subject to the destination website's privacy terms.

The entire data/ football content package is a separate component outside that proprietary licence. Software dependencies and other third-party material remain subject to their respective licences, terms and rights.

CalcioTotale is an unofficial project and is not affiliated with, endorsed by or sponsored by football federations, leagues, competitions, clubs or players.

Italiano

Informativa sulla Privacy

CalcioTotale versione 1.0.1 è un'applicazione manageriale calcistica locale e per giocatore singolo, sviluppata con Python e PySide6 e accompagnata da un pacchetto separato e sostituibile di contenuti calcistici 2026-27. L'ambiente di riferimento è Linux desktop. L'interfaccia è disponibile in italiano e inglese: l'italiano viene selezionato automaticamente soltanto quando la lingua del sistema è l'italiano, mentre per qualsiasi altra lingua di sistema viene usato l'inglese. L'applicazione simula stagioni calcistiche, gestione del club e della squadra, finanze, mercato, marketing, strutture e partite.

L'applicazione non raccoglie, trasmette, vende o condivide dati personali. Tutte le logiche di gioco e simulazione vengono eseguite localmente sul dispositivo dell'utente. CalcioTotale non richiede account, telemetria, analytics, servizi pubblicitari o server remoto e il runtime non effettua intenzionalmente richieste di rete durante il normale utilizzo.

L'utente può inserire un nome visualizzato per il profilo dell'amministratore delegato. Se sceglie di indicare un nome reale o un altro testo identificativo, quel testo viene conservato esclusivamente nei file locali della carriera. I salvataggi possono contenere anche club selezionato, modalità carriera, livello di controllo gestionale scelto, rose, staff, calendari, risultati, finanze, trasferimenti, strutture, notizie e gli altri dati necessari a ripristinare l'avanzamento.

Nessun nome profilo, contenuto dei salvataggi, club selezionato, risultato o altro dato di avanzamento viene inviato dall'applicazione a Eleòra o a servizi esterni.

I seguenti file locali vengono letti o possono essere scritti durante l'uso normale:

  • Dati della carriera Fino a nove slot vengono salvati come JSON compresso con gzip in user/slotN.json.gz. Le build portabili Windows e Linux mantengono questa cartella accanto all'eseguibile; il pacchetto RPM per Fedora usa ${XDG_DATA_HOME:-$HOME/.local/share}/calciototale/user/; macOS usa ~/Library/Application Support/CalcioTotale/user/. I file restano sul dispositivo salvo copia, backup o condivisione da parte dell'utente.
  • Riepiloghi degli slot Il gioco può creare user/slotN.meta.json, un riepilogo in JSON non compresso usato dalla schermata di caricamento e contenente soltanto nome profilo, club, modalità carriera, livello di controllo gestionale e data di gioco.
  • Preferenze locali user/preferences.json può conservare la lingua dell'interfaccia selezionata e altre preferenze locali di visualizzazione. La lingua scelta dal menu di gioco viene applicata al successivo avvio; un secondo clic sullo stesso comando prima del riavvio annulla la modifica pendente. Il file non contiene dati della carriera né identificativi online.
  • Pacchetto separato di contenuti calcistici Il pacchetto sostituibile nella cartella data/ è separato dall'applicazione. I dati JSON compressi con gzip vengono letti per inizializzare club, giocatori, contenuti stagionali e colori e schemi usati per generare le magliette identificative delle squadre. Le immagini locali associate sono utilizzate per la grafica delle competizioni.
  • Asset locali Immagini, font, icone e grafiche dell'interfaccia vengono caricati dalla cartella locale assets/. Non vengono scaricati a runtime.
  • Cache temporanee Nella directory temporanea del sistema possono essere generate copie PNG sostituibili delle icone locali, attualmente in calciototale_news_icons e calciototale_icon_cache. Non contengono dati di carriera o del profilo.
  • Rilevamento schermo All'avvio può essere creato nella directory temporanea del sistema un file di breve durata calciototale-display-*.json, usato per passare geometria e fattore di scala dello schermo principale tra processi locali dell'applicazione. Il gioco lo rimuove dopo il rilevamento e il file non contiene dati di carriera o del profilo.

Il gioco non crea profili online, identificativi persistenti di telemetria, cookie o backup cloud. Non sono richiesti privilegi di amministratore. L'applicazione viene eseguita come utente corrente e necessita di scrittura solo dove vengono conservati i salvataggi locali e i file temporanei del sistema operativo.

L'utente controlla questi file locali e può rimuovere una carriera eliminando i relativi file slotN.json.gz e slotN.meta.json. Eliminando preferences.json vengono ripristinate le preferenze predefinite dell'interfaccia, compresa la selezione della lingua secondo la regola di sistema descritta sopra. Anche le cache temporanee delle icone possono essere eliminate e vengono rigenerate quando necessario. Le copie prodotte da backup, programmi di sincronizzazione o condivisione manuale dipendono dall'utente e dal servizio terzo scelto, non da CalcioTotale.

Il dialog Informazioni contiene link alle pagine ufficiali Eleòra. Vengono aperti nel browser predefinito dell'utente soltanto quando selezionati. Il gioco non invia con tali link dati di carriera o del profilo; l'eventuale connessione successiva è effettuata dal browser ed è soggetta all'informativa privacy del sito di destinazione.
