Privacy Policy

CalcioTotale version 1.0 beta is a local, single-player football management game built with Python and PySide6. Its reference environment is desktop Linux. The game simulates football seasons, club and squad management, finances, transfers, marketing, facilities and matches.

The application does not collect, transmit, sell or share personal data. All gameplay and simulation logic run locally on the user's device. CalcioTotale does not require an account, telemetry, analytics, advertising services or a remote server, and the runtime does not intentionally make network requests during normal gameplay.

The user may enter a display name for the president/managing director profile. If the user chooses to enter a real name or other identifying text, that text is stored only inside the local career files. Save data may also include the selected club, game mode, squads, staff, fixtures, results, finances, transfers, facilities, news and the other information needed to restore game progress.

No profile name, save payload, selected club, match result or other progress data is sent by the application to Eleòra or to an external service.

The following local files are read or may be written during normal use:

  • Career payloads Up to nine slots are stored as gzip-compressed JSON in saves/slotN.json.gz. Portable Windows and Linux builds keep this directory beside the executable; the Fedora RPM uses ${XDG_DATA_HOME:-$HOME/.local/share}/calciototale/saves/; macOS uses ~/Library/Application Support/CalcioTotale/saves/. The files remain on the user's device unless the user copies, backs up or shares them.
  • Slot summaries The game may create saves/slotN.meta.json with a plain-JSON summary used by the load screen, containing only profile name, club, game mode and in-game date.
  • Game database The bundled database in data/data.json.gz is gzip-compressed JSON and is read locally to initialize clubs, competitions, players and season data.
  • Local assets Images, fonts, icons and UI graphics are loaded from the local assets/ directory. They are not downloaded at runtime.
  • Temporary caches Replaceable PNG renderings of local icons may be generated under the operating system's temporary directory, currently in calciototale_news_icons and calciototale_icon_cache. They contain no career or profile data.
  • Display probe At startup, a short-lived calciototale-display-*.json file may be created in the operating system's temporary directory to pass the primary display geometry and scaling factor between local application processes. The game removes it after the probe and it contains no career or profile data.

The game does not create an online profile, persistent telemetry identifier, cookie or cloud backup. Root or administrator privileges are not required. The application runs as the current user and needs write access only where its local saves and operating-system temporary files are stored.

The user controls these local files and can remove career data by deleting the corresponding slotN.json.gz and slotN.meta.json files. Temporary icon caches can also be deleted and are regenerated when required. Copies created through backups, synchronisation software or manual sharing are controlled by the user and by the chosen third-party service, not by CalcioTotale.

The About dialog contains links to official Eleòra pages. They are opened in the user's default browser only when selected. The game does not send career or profile data with those links; any subsequent connection is made by the browser and is subject to the destination website's privacy terms.

The importer and maintenance programs under tools/ are separate development utilities and may access third-party websites when an authorised collaborator runs them. They are not invoked by the game runtime and are outside normal gameplay covered by the no-network statement above.

Licensing and third-party rights are documented separately in LICENSE, THIRD_PARTY_NOTICES.md and the licenses/ directory. The original CalcioTotale material is proprietary. PySide6/Qt, Exo 2 under the OFL 1.1, applicable Google icons under Apache 2.0, applicable flag-icons SVGs under the MIT License and football-related names, marks and data remain subject to their respective licences, terms and rights.

CalcioTotale is an unofficial project and is not affiliated with, endorsed by or sponsored by football federations, leagues, competitions, clubs or players.

Italiano

Informativa sulla Privacy

CalcioTotale versione 1.0 beta è un gioco manageriale calcistico locale e per giocatore singolo, sviluppato con Python e PySide6. L'ambiente di riferimento è Linux desktop. Il gioco simula stagioni calcistiche, gestione del club e della squadra, finanze, mercato, marketing, strutture e partite.

L'applicazione non raccoglie, trasmette, vende o condivide dati personali. Tutte le logiche di gioco e simulazione vengono eseguite localmente sul dispositivo dell'utente. CalcioTotale non richiede account, telemetria, analytics, servizi pubblicitari o server remoto e il runtime non effettua intenzionalmente richieste di rete durante il normale utilizzo.

L'utente può inserire un nome visualizzato per il profilo Presidente/Amministratore Delegato. Se sceglie di indicare un nome reale o un altro testo identificativo, quel testo viene conservato esclusivamente nei file locali della carriera. I salvataggi possono contenere anche club selezionato, modalità, rose, staff, calendari, risultati, finanze, trasferimenti, strutture, notizie e gli altri dati necessari a ripristinare l'avanzamento.

Nessun nome profilo, contenuto dei salvataggi, club selezionato, risultato o altro dato di avanzamento viene inviato dall'applicazione a Eleòra o a servizi esterni.

I seguenti file locali vengono letti o possono essere scritti durante l'uso normale:

  • Dati della carriera Fino a nove slot vengono salvati come JSON compresso con gzip in saves/slotN.json.gz. Le build portabili Windows e Linux mantengono questa cartella accanto all'eseguibile; il pacchetto RPM per Fedora usa ${XDG_DATA_HOME:-$HOME/.local/share}/calciototale/saves/; macOS usa ~/Library/Application Support/CalcioTotale/saves/. I file restano sul dispositivo salvo copia, backup o condivisione da parte dell'utente.
  • Riepiloghi degli slot Il gioco può creare saves/slotN.meta.json, un riepilogo in JSON non compresso usato dalla schermata di caricamento e contenente soltanto nome profilo, club, modalità e data di gioco.
  • Database di gioco Il database incluso in data/data.json.gz è JSON compresso con gzip e viene letto localmente per inizializzare club, competizioni, giocatori e dati stagionali.
  • Asset locali Immagini, font, icone e grafiche dell'interfaccia vengono caricati dalla cartella locale assets/. Non vengono scaricati a runtime.
  • Cache temporanee Nella directory temporanea del sistema possono essere generate copie PNG sostituibili delle icone locali, attualmente in calciototale_news_icons e calciototale_icon_cache. Non contengono dati di carriera o del profilo.
  • Rilevamento schermo All'avvio può essere creato nella directory temporanea del sistema un file di breve durata calciototale-display-*.json, usato per passare geometria e fattore di scala dello schermo principale tra processi locali dell'applicazione. Il gioco lo rimuove dopo il rilevamento e il file non contiene dati di carriera o del profilo.

Il gioco non crea profili online, identificativi persistenti di telemetria, cookie o backup cloud. Non sono richiesti privilegi di amministratore. L'applicazione viene eseguita come utente corrente e necessita di scrittura solo dove vengono conservati i salvataggi locali e i file temporanei del sistema operativo.

L'utente controlla questi file locali e può rimuovere una carriera eliminando i relativi file slotN.json.gz e slotN.meta.json. Anche le cache temporanee delle icone possono essere eliminate e vengono rigenerate quando necessario. Le copie prodotte da backup, programmi di sincronizzazione o condivisione manuale dipendono dall'utente e dal servizio terzo scelto, non da CalcioTotale.

Il dialog Informazioni contiene link alle pagine ufficiali Eleòra. Vengono aperti nel browser predefinito dell'utente soltanto quando selezionati. Il gioco non invia con tali link dati di carriera o del profilo; l'eventuale connessione successiva è effettuata dal browser ed è soggetta all'informativa privacy del sito di destinazione.

L'importer e i programmi di manutenzione in tools/ sono strumenti di sviluppo separati e possono accedere a siti di terze parti quando vengono avviati da un collaboratore autorizzato. Non sono richiamati dal runtime del gioco e restano fuori dal normale utilizzo cui si riferisce la dichiarazione sull'assenza di rete.

Licenze e diritti di terze parti sono documentati separatamente in LICENSE, THIRD_PARTY_NOTICES.md e nella cartella licenses/. I materiali originali di CalcioTotale sono proprietari. PySide6/Qt, Exo 2 sotto OFL 1.1, le icone Google applicabili sotto Apache 2.0, gli SVG flag-icons applicabili sotto licenza MIT e nomi, marchi e dati calcistici restano soggetti alle rispettive licenze, condizioni e diritti.

CalcioTotale è un progetto non ufficiale e non è affiliato, approvato o sponsorizzato da federazioni calcistiche, leghe, competizioni, club o giocatori.
